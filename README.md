# Adrija Chatterjee Portfolio

Adrija Chatterjee’s personal portfolio, showcasing her education, experience, projects, skills, and leadership. Built with Next.js, React, and Tailwind CSS. Profile content lives in `src/data/resume.tsx`; Adrija’s original CV is served from `public/resume.pdf`.

Connect with Adrija on [GitHub](https://github.com/Adrijaww), [LinkedIn](https://www.linkedin.com/in/adrija-chatterjee-346a87321/), and [X](https://x.com/awdrij44).

Run `npm run dev` for development and `npm run build` for production. Set `NEXT_PUBLIC_SITE_URL` to the deployed origin for canonical URLs, sitemap, and structured metadata. It defaults to `http://localhost:3000` for local development.
